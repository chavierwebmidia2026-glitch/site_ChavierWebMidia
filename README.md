* Git

## 🎨 Layout

Header e Footer utilizam gradiente personalizado:

```css
background: linear-gradient(
    256deg,
    rgba(0, 14, 36, 1) 0%,
    rgba(9, 9, 121, 0.6) 35%,
    rgba(0, 212, 255, 1) 100%
);
```

As cores principais são organizadas através do `:root`.
